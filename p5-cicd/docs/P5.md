## 1. (P5.1) Rancangan pipeline
Tahap dan gate, alasan urutan, kebijakan tag image, cara secret diberikan, rencana rollback kode dan migrasi.

## 2. (P5.2) Bukti run
Tautan run lulus (pull request dan push ke main), run gagal di test, run gagal di smoke test, beserta penjelasan.

## 3. (P5.2) Bukti rollback lokal
Output `rollout status`, `rollout undo`, `rollout history` (scripts/rollback_demo.sh), waktu pemulihan.

## 4. (P5.2) Bukti gate rantai pasok
Potongan output Grype dari job build (jumlah temuan per tingkat keparahan, dan keputusan lulus/gagal).
Isi SBOM image: `docker buildx imagetools inspect ghcr.io/<owner>/musiwatch-api:<sha> --format '{{ json .SBOM }}'`
(cukup jumlah paket dan tiga contoh). Pilih satu action di workflow, cocokkan SHA-nya dengan tag rilis di GitHub,
dan jelaskan mengapa SHA lebih aman daripada tag.

## 5. (P5.3) Dokumentasi
